# UI kit — fabryka.ai (marketing site)

Click-through recreation of the site direction in the brief: editorial, document-like, not componentised SaaS UI.

- `index.html` — mounts the site with a view switcher (home / production / laboratory / CodeSOTA).
- `Chrome.jsx` — sticky 56px top rail (wordmark, mono nav, LIVE badge) and the carbon footer with coordinates.
- `Home.jsx` — §00 rail, 132px campaign headline, production plate, carbon metric band, FIG. 01 photo frame, numbered sections 01/02/03, live machine log + line table.
- `Pages.jsx` — `Production` (line tabs, plate per line, endpoint block, price table, deploy dialog) and `Laboratory` (experiment cards, model shelf table).

Every surface is composed from the published components — no kit-local primitives. Photography frames are intentionally empty until real hardware photographs exist.
