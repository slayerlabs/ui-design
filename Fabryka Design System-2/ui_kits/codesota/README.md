# UI kit — CodeSOTA (measurement)

CodeSOTA is the measurement layer, presented as semi-independent: "Measurement by Fabryka." in the header, `A FABRYKA PROJECT` as the endorsement, and Fabryka's own models measured alongside everyone else's — including a failing laboratory checkpoint.

- `index.html` — leaderboard view plus the shared Fabryka footer.
- `Leaderboard.jsx` — carbon masthead with measurement readouts, suite tabs (Polish legal QA / Tool calling / JSON conformance), the results table (rank, model, provider, score, tok/s, cost, result) and a click-through per-model test plate (`MachineLog` + `TestStamp`).

Scores and suites are plausible placeholders, not real measurements.
