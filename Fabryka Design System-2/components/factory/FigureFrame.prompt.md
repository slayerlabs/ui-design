# FigureFrame
Annotated frame for hard-flash hardware photography or a technical chart, captioned like a manual plate.

```jsx
<FigureFrame figure="FIG. 04" caption="Machine F-WAW-002" annotations={["NVIDIA RTX 3090 x 2","48 GB VRAM","2026-09-03"]} />
```

Leave `src` empty to hold space for a real photograph — do not fill it with stock imagery. Images are desaturated by default.
