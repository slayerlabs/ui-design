# Wordmark
The FABRYKA. wordmark set in type — use it in every header, plate and slide; never draw a symbol for the brand.

```jsx
<Wordmark size={28} unit="OPEN MODEL FACTORY" place="WARSAW / PL" />
<Fmark size={40} tone="red" />
```

The period is always present and always red (`periodColor`). `Fmark` is the square `F.` badge for avatars, stickers, rack labels and repo marks — tones `red` / `carbon` / `outline`. On carbon backgrounds pass `tone="inverse"`.
